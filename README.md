# Python-DnD-Site-Base
This was a final project for my Web Development I class that I plan to make better as time goes on, even after the submission date. It is a database based python site that allows you to link a DnD character to a username and password. It gives them randomized stats, but that is currently it.

It is overall a site with the ability to create a new user, login as an already inputted user, update a current user, and the ability to view all users. It does not have the ability to link multiple characters to one specific username yet, it does not allow for input stats, and it does not add the stats from the race chosen. I very much want to add all of these over the course of being outside of my class and slowly get better at Python and keep up on coding in a fun way.

Overall, you only really need a python based coding program, mainly either Virtual Studio Code or Pycharm. After you install the project, you'd open up the program, go to the top left of the screen, open up File or the hamburger, and open up the project in wherever it installed to. It's the entire file
